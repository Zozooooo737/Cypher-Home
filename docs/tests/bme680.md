## Câblage testé

| Broche du composant (nom officiel) | Broche de la carte | Remarque |
|---|---|---|
| VIN | 5V | VCC dans le manuel |
| GND | GND | |
| SDI | SDA | SDA dans le manuel ; bus I2C partagé avec la caméra |
| SCK | SCL | SCL dans le manuel ; bus I2C partagé avec la caméra |
| SDO | GND | SD0 dans le manuel ; fixe l'adresse à 0x76 |
| CS | non connectée | |
| 3Vo | non connectée | Non documentée dans le manuel |

- Bus et adressage : I2C, adresse 0x76 (0x77 par défaut d'après le manuel, 0x76 si SDO est relié à GND).
- Éléments ajoutés : aucun.
- Cette table est le câblage **testé** le 2026-11-08. `pins.h` donne le câblage courant, et la table D3 validée fait foi.

## Logiciel

- Bibliothèque : Adafruit BME680 Library 2.0.6, avec Adafruit BusIO 1.17.4 et Adafruit Unified Sensor 1.1.15.
- Lignes `lib_deps` (`firmware/platformio.ini`) : `adafruit/Adafruit BME680 Library@2.0.6`, `adafruit/Adafruit BusIO@1.17.4`, `adafruit/Adafruit Unified Sensor@1.1.15`.
- Compatibilité UNO R4 WiFi : oui sur cette carte (valeurs lues le 2026-11-08).
- Fichier du dépôt : `firmware/src/components/bme680.cpp`.
- Paramètres clés : adresse I2C `BME680_I2C_ADDRESS` = 0x76 (`config.h`) ; réglages de mesure dans `bme680.cpp`.
- Alternatives écartées :
  - SPI (D1) : le bus SPI reste réservé à la caméra et à l'écran.
  - BSEC : pas d'indice IAQ, seule la résistance du gaz brute est exposée.

## Résultat

- Intégrité : fonctionnel ; BME680 lu à chaque passe sur 9 passes consécutives de `self_test_run()` (environ 6 s d'intervalle, environ 50 s au total).
- Sortie type de `bme680_test()` :

```
[bme680] temperature ........... 23.73 C
[bme680] humidite .............. 49.86 %
[bme680] pression .............. 1008.40 hPa
[bme680] gaz ................... 253.28 kOhm
```

- Mesures sur les 9 passes :

| Grandeur | Première passe → dernière passe | Remarque |
|---|---|---|
| Température | 23,73 à 23,77 °C | |
| Humidité | 49,86 à 49,59 % | Légère baisse régulière |
| Pression | 1008,40 à 1008,39 hPa | |
| Résistance du gaz | 253,28 à 263,32 kOhm | Hausse lente |

- Débranchement :
  - BME680 débranché : une seule ligne `[bme680] KO`, le self-test continue.
  - Rebranché : les valeurs reviennent à la passe suivante, sans redémarrer la carte.
  - Débranchement de l'alimentation : `[camera] KO` et `[bme680] KO`, une ligne chacun.

## Pièges et limites

- Résistance du gaz encore en hausse à la fin du test.
- Compatibilité 5 V des lignes I2C déduite du schéma du manuel, non écrite explicitement.
- 3Vo non documenté dans le manuel.
- Non testé :
  - comparaison avec un thermomètre de référence ;
  - courant consommé (reporté à la fin du projet, courant total, P1.7).
